# No Net — المشروع الكامل الأولي

المجلد يحتوي على تطبيق المستخدم `NoNet`، وتطبيق الإدارة `NoNet_Admin`، وخادم API مشترك `Backend`، وسير عمل GitHub Actions لبناء ملفي APK.

## قبل بناء APK
1. انشر مجلد `Backend` على خادم يدعم Docker مع نطاق HTTPS.
2. اضبط أسرار الخادم في `Backend/.env` كما هو موضح في `Backend/README_AR.md`.
3. افتح No Net واضبط رابط الخادم من «إعدادات الاتصال بالخادم».
4. افتح No Net Admin واضبط الرابط نفسه ثم سجّل الدخول ببيانات الأدمن التي وضعتها في `.env`.
5. ارفع المجلد الكامل إلى مستودع GitHub. من تبويب Actions شغّل `Build No Net and No Net Admin APKs` أو ادفع تحديثاً إلى `main`.
6. نزّل artifact باسم `NoNet-and-Admin-debug-apks` بعد نجاح البناء. هذه APKs تجريبية موقعة بمفتاح debug وليست إصدار متجر.

## ما يتضمنه هذا الإصدار
- خدمة VPN محلية في أندرويد تستخدم قائمة التطبيقات المسموح إدخالها للنفق ثم تُسقط حزمها، بحيث لا تمر التطبيقات غير المختارة داخل النفق.
- اختيار الحجب: بيانات الهاتف، Wi-Fi، أو الاثنين، مع إعادة تقييم الوضع عند تغير الشبكة.
- واجهات طلب الاشتراك، طرق التواصل SMS/WhatsApp/Telegram، خادم مشترك، لوحة إدارة للطلبات، تأكيد دفع يدوي، تفعيل وإلغاء الاشتراك، سعر صرف وسجل تدقيق.
- تحقق من الاشتراك عند فتح التطبيق ومهمة دورية كل 3 أيام. فشل الاتصال بالشبكة أو الخادم لا يغيّر حالة الاشتراك السابقة تلقائياً.

## حدود يجب معرفتها بوضوح
- لم يتم بناء APK أو اختبار السلوك على جهاز Android في بيئة العمل الحالية، لذلك لا يمكن الادعاء أن النسخة اجتازت اختباراً فعلياً. يجب اختبار الحجب على عدة أجهزة وشبكات قبل الاستخدام.
- سياسة 12 ساعة والفرصة المجانية الواحدة وإدارة أعطال الخادم لم تكتمل بعد على مستوى دورة حياة الاشتراك، ومذكورة في README الخادم. لا تستخدم هذه النسخة تجارياً قبل استكمالها واختبارها.
- تطبيق No Net يحتاج موافقة المستخدم على VPN. قد تتعارض خدمة VPN مع VPN آخر أو بعض إعدادات الشركات. حجب بيانات الهاتف مقابل Wi-Fi يعتمد على الشبكة الافتراضية النشطة في أندرويد، ويحتاج اختباراً على الأجهزة المستهدفة.
- `QUERY_ALL_PACKAGES` مطلوب لعرض التطبيقات المثبتة، وقد يفرض قيوداً عند النشر على Google Play. هذه النسخة مهيأة للاختبار والتوزيع المباشر.
- تفعيل الاشتراك يدوي فقط. لا توجد بوابة دفع إلكترونية.
- قبل الاستخدام الحقيقي، أكمل سياسة التحقق والمهلة، اختبر أمن الخادم، أعد إعدادات النسخ الاحتياطي، ووقّع APK بمفتاح إصدار خاص بك.
